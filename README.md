# Sidharth weds Jaya

This repository holds the wedding invitation website of Sidharth and Jaya.

index.html is the card, invitation.jpg is the picture shown beside its link, and sheet.txt holds the link of the private guest sheet. CNAME tells GitHub the name of the website. music.mp3 is the music the card plays, an original piece made for this card. Please leave every file in place.

The ek-saal folder holds a separate page made for Jaya on the first anniversary of the day Sidharth and Jaya met, 20 October. It lives at sidharthwedsjaya.life/ek-saal/ and is not linked from the card.
